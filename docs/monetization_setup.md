# 定番メシ 収益化検討の保留記録

最終更新日: 2026年8月16日

## 現在の方針

定番メシは、広告なし、アプリ内課金なし、機能制限なしの無料アプリとして提供する。

- Google Mobile Ads SDKはアプリとXcodeプロジェクトから削除する
- StoreKit 2の購入処理とPro案内は削除する
- 店、注文セット、写真の登録数を制限しない
- 店のピン留め数を制限しない
- ピン留め店の手動並び替えを全員に提供する
- App Store ConnectのApp Privacyは実装に合わせてデータ収集なしへ戻す

## 外部サービスに残る設定

過去の検討で、App Store Connectに非消費型App内課金 `com.okapiron.TeibanMeshi.pro`、AdMobに定番メシのアプリと広告ユニットを作成した。これらは現在のリリースでは使用、提出しない。

履歴を保つため、外部サービス上の設定を直ちに削除する必要はない。ただし、App Reviewの下書きからApp内課金を外し、広告または課金を含むBuild `10`は提出しない。

## 再検討条件

収益化は、以下を満たした後に別の企画として判断する。

1. 無料アプリとして十分な利用者と継続利用がある
2. 検索、登録、即参照の品質に重大な課題がない
3. 収益化が注文直前の体験を損なわない
4. 既存利用者のデータや機能を不当に制限しない
5. 実装前に仕様、プライバシーポリシー、App Store申告を更新する

以前の価格や広告配置は確定事項として扱わない。再開する場合は、改めてユーザーの意思決定を得る。
