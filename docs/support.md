# 定番メシ サポート

定番メシは、よく行くお店で自分の定番注文をすぐ思い出すための個人用メモアプリです。

## お問い合わせ

不具合報告、改善要望、使い方に関する質問は、GitHub Issueからご連絡ください。

[GitHub Issueで問い合わせる](https://github.com/okapiron/teibanmeshi/issues/new)

## 問い合わせ時に書いてほしいこと

- 使っている端末
- iOSのバージョン
- アプリのバージョン
- 起きていること
- 期待していた動き
- 再現手順

## よくある確認事項

### データはどこに保存されますか？

登録した店名、注文内容、メモは端末内に保存されます。ログインやクラウド同期はありません。

### 店名を変更したいです

店詳細画面の右上メニューから「店名を変更」を選ぶと、その店に紐づく注文メモを残したまま店名を変更できます。

### 注文メモを別の店に移動できますか？

現在のMVPでは、保存済みの注文メモを別の店へ付け替える機能はありません。誤操作で記録が消えたように見えることを避けるため、注文メモの編集画面では店名を変更できない仕様にしています。
