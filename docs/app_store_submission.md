### 説明

```text
定番メシは、よく行くお店で自分の定番注文を保存して、注文前にすぐ見返せるアプリです。

松屋、サイゼリヤ、スタバ、丸亀製麺、マクドナルド、町中華、ラーメン店などで、前に頼んでよかった組み合わせや、次に試したいメニューをメモしておけます。

店名と注文内容を入力するだけ。
注文内容は複数行でサクッと登録できます。

登録した注文は「定番」「次試す」「試した」の3つに分けて整理できます。
店詳細では定番がすぐ見えるので、注文前に迷わず「いつもの」を思い出せます。

登録済みの店は検索、最近見た店、店一覧からすばやく探せます。
ログイン不要、通信不要。自分だけの注文メモとして気軽に使えます。
```

## App Privacy 入力方針

このMVPは、ユーザーの注文メモを端末内に保存するだけで、開発者側へ送信しない。

App Store ConnectのApp Privacyでは以下の方針。

- トラッキング: しない
- 第三者広告: なし
- サードパーティSDK: なし
- 開発者が収集するデータ: なし
- 位置情報: 使わない
- 連絡先: 使わない
- 写真: ユーザーが任意で選択または撮影し、端末内にのみ保存する
- カメラ: ユーザーが写真撮影を選んだ場合にのみ使用する
- アカウント作成: なし
- ログイン: なし

申告の考え方:

```text
Data Not Collected
```

ユーザーが入力する店名、注文内容、メモ、写真は端末内ローカル保存のみで、開発者や第三者へ送信しない。

## 輸出コンプライアンス

`TeibanMeshi/Resources/Info.plist` に以下を設定済み。

```xml
<key>ITSAppUsesNonExemptEncryption</key>
<false/>
```

アプリ内で独自暗号化、通信、暗号ライブラリ、認証、クラウド同期は使用していない。

## 審査メモ案

```text
このアプリは、よく行く飲食店で自分の定番注文を保存し、注文前にすぐ確認するための個人用メモアプリです。

ログインやアカウント作成は不要です。
通信機能、SNS共有、地図、店舗レビュー、決済機能はありません。
データは端末内にのみ保存されます。

テスト手順:
1. 「新しく記録」から店名と注文内容を入力して保存します。
2. 店詳細で「定番」「次試す」「試した」の順に注文メモが表示されることを確認します。
3. ホーム検索で店名、注文内容、メモから検索できることを確認します。
4. 店一覧で五十音順・追加順を切り替えて店を探せることを確認します。
```
