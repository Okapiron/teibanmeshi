# 定番メシ

定番メシは、お気に入りのお店で自分のいつもの注文をすぐ思い出すための日本向けiPhoneアプリです。

食事日記や店舗レビューではなく、店に入る直前、レジ前、券売機前、注文直前に「この店で何を頼むんだっけ？」を即確認するための、自分だけの定番注文メモを目指します。

## 開発方針

- ログインなし
- ローカル保存
- 通信なし
- 店名だけで店舗登録
- 注文内容は複数行自由入力
- 状態は「定番」「次試す」「試した」
- ホームは検索と最近見た店を中心に軽くする
- 店詳細は「定番 -> 次試す -> 試した」の順で高密度表示する
- 写真は任意で、主役にしない

MVPでは、SNS、地図、クラウド同期、AI提案、店舗レビュー、価格専用欄、カロリー管理は実装しません。

## 技術

MVPの実装技術:

- SwiftUI
- SwiftData
- iOS 17以降
- ローカルファースト

現在はSwiftUI + SwiftDataのMVP実装済みで、TestFlight向けビルドをアップロード済みです。
